# Kinderkunst

Das Archiv für die Kunstwerke eurer Kinder: Fotos, Entstehungsdatum, Alter, Geschichten als Text und Tonaufnahme, Tags.

Neue Funktionen bitte zuerst im Add-on **„Kinderkunst (Test)“** ausprobieren. Hier liegen eure echten Daten.

## Öffnen

„Kinderkunst“ in der Seitenleiste von Home Assistant, auch in der Companion-App. Angemeldet seid ihr über euer Home-Assistant-Konto.

## Daten und Backup

Datenbank, Fotos und Tonaufnahmen liegen im Datenordner dieses Add-ons auf dem Home-Assistant-Rechner und verlassen ihn nicht. Sie sind Teil des Home-Assistant-Backups; dafür wird das Add-on kurz angehalten. **Bitte regelmäßige Backups einrichten** (Einstellungen → System → Backups), am besten zusätzlich auf ein anderes Gerät oder Laufwerk.

## Neue Version holen

Nach einem neuen Meilenstein im Add-on auf **„Neu bauen“** tippen.
