# Kinderkunst (Test)

Testkanal der Kinderkunst-App. **Bitte nur erfundene Testdaten verwenden** – das echte Archiv kommt in ein eigenes Add-on „Kinderkunst“.

## Öffnen

Nach dem Start erscheint „Kinderkunst Test“ in der Seitenleiste von Home Assistant, in der Companion-App ebenso. Die Anmeldung läuft über euer Home-Assistant-Konto, es gibt kein zweites Passwort.

## Technik-Test

Unter „Technik-Test“ (oder über das Zahnrad) prüft ihr:

1. Fotos über Kamera und Galerie hochladen, auch mehrere große auf einmal
2. Mikrofon: Aufnahme, Abspielen, Speichern
3. Live-Kamera
4. Wer angemeldet ist und wie viel Speicher frei ist

## Daten und Backup

Datenbank und Fotos liegen im Datenordner dieses Add-ons und sind Teil des Home-Assistant-Backups. Für das Backup wird das Add-on kurz angehalten.

## Neue Version holen

Gibt es eine neue Version, zeigt Home Assistant beim Add-on ein **Update** an. Was neu ist, steht in den Release-Notizen („Änderungen“). Die Versionsnummer ist das Datum mit Uhrzeit, z. B. `2026.11.26.0748`.

## Über dieses Add-on

Privates Familienprojekt, nicht für die Öffentlichkeit bestimmt. Entwickelt großteils mit dem KI-Assistenten Claude (Anthropic); jede Änderung prüft ein Mensch. In der App selbst steckt keine KI: Fotos und Aufnahmen verlassen den Home-Assistant-Rechner nicht.
